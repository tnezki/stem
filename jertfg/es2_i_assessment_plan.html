STEM I – ES2-I Assessment Plan

Essential Standard

Students will generate, evaluate, and justify engineering solutions using evidence, trade-offs, and design criteria.

Learning Targets

Learning Target 2.1: Generating Multiple Design Ideas

Referenced Challenges: Trebuchet, Zip Line Racer, Water Rocket Hang Time, Design Your Own Challenge

  • I can generate multiple solutions to an engineering problem.
  • I can create sketches that communicate design ideas.
  • I can identify strengths and weaknesses of different concepts.
  • I can build upon ideas developed by teammates.
  • I can use brainstorming techniques to increase creativity.

Learning Target 2.2: Evaluating Design Alternatives

Referenced Challenges: Trebuchet, Maximum Distance Racer, Tower Strength

  • I can compare competing design solutions.
  • I can identify trade-offs between cost, performance, and reliability.
  • I can use criteria and constraints to evaluate solutions.
  • I can use evidence to rank design alternatives.
  • I can select a design that best meets project goals.

Learning Target 2.3: Justifying Engineering Decisions

Referenced Challenges: Hydraulics, Maximum Distance Racer, Design Your Own Challenge

  • I can explain why a design was selected.
  • I can defend design decisions using evidence.
  • I can justify trade-offs made during planning.
  • I can explain how criteria and constraints influenced decisions.
  • I can communicate engineering reasoning clearly.

Assessment Methods by DOK Level

DOK 1 — Rungs 1–2

Purpose: Determine whether students can generate and recognize multiple engineering solutions.

  • Brainstorming Sprint
  • Sketch Identification Task
  • Criteria vs Constraint Sort
  • Design Alternative Recognition Check
DOK 2 — Rungs 3–4

Purpose: Determine whether students can compare solutions and evaluate alternatives.

  • Design Comparison Task
  • Trebuchet Concept Ranking Activity
  • Zip Line Racer Design Analysis
  • Decision Matrix Construction Task
DOK 3 — Rungs 5–6

Purpose: Determine whether students can justify engineering decisions using evidence.

  • Decision Matrix Defense
  • Maximum Distance Racer Design Justification
  • Engineering Trade-Off Analysis
  • Design Review Board Response
DOK 4 — Rungs 7–8

Purpose: Determine whether students can defend and critique engineering solutions in unfamiliar contexts.

  • Critique and Redesign Task
  • Engineering Proposal Defense
  • Challenge Design Evaluation
  • Design Your Own Challenge Planning Task

Summative Assessment Plan

Students demonstrate proficiency through engineering artifacts rather than traditional tests.

Artifact Options

  • Decision Matrix Report
  • Engineering Sketch Portfolio
  • Blueprint Package
  • Design Review Board Defense
  • Engineering Proposal
  • Design Justification Video

Challenge Connections

  • Trebuchet → Decision Matrix Report
  • Maximum Distance Racer → Design Review Defense
  • Zip Line Racer → Engineering Sketch Portfolio
  • Design Your Own Challenge → Full Engineering Proposal

Holistic Rubric

A — Highly Proficient

The student generates innovative solutions, evaluates alternatives using evidence, clearly justifies engineering decisions, and defends choices using criteria, constraints, and data.

B — Proficient

The student develops multiple solutions, compares alternatives, and provides reasonable evidence-based justification for design decisions.

C — Developing Proficiency

The student can generate solutions and make basic comparisons but struggles to justify decisions using strong evidence.

Not Yet

The student provides limited evidence of design evaluation, justification, or engineering reasoning.
